
# AutoApplyMAX

## Description

AutoApplyMAX is a browser extension that helps you automate the process of filling out and submitting online forms, particularly for job applications.

## Features

- Automatically fills in form fields based on your saved profile.
- One-click submission for supported websites.
- Simple and intuitive user interface.

## Installation

1.  Download the latest release from the [releases page](https://github.com/Stem0794/AutoApplyMAX/releases).
2.  Unzip the downloaded file.
3.  Open your browser's extension management page (e.g., `chrome://extensions` in Chrome).
4.  Enable "Developer mode".
5.  Click "Load unpacked" and select the unzipped directory.

## Usage

1.  Click on the AutoApplyMAX extension icon in your browser's toolbar to open the settings page.
2.  Fill in your personal information to create your profile.
3.  Navigate to a supported job application website.
4.  Click the "Auto Apply" button to automatically fill and submit the application.
